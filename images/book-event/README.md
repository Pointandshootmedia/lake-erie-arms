# Book An Event page photos

Add your images to this folder. Use these filenames (or update `book-an-event.html` if you use different names).

| Filename | Where it appears |
|----------|------------------|
| murder-mystery.webp | Hero background / banner at top of Book An Event page (wide image; 21:9 ratio works well) |
| media-room.webp | Media Room card in "Choose the Perfect Space" |
| large-event-room.webp | Large Event Room card in "Choose the Perfect Space" |

You can use `.webp`, `.jpg`, or `.png`. If you use another extension, update the `src` in `book-an-event.html` to match.

Until these files are added, the hero and venue cards will show a neutral background where the images go.

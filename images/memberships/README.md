# Memberships page images

Images used on the Memberships page:

- **lea2803.webp** — Facility image (gallery / amenities section)
- **benefits.webp** — Membership Benefits section (e.g. USCCA benefits)
- **american-flag.webp** — Hero Discount section
- **corporate.webp** — Corporate Memberships section

To add more gallery images later, name them `gallery-2.webp`, `gallery-3.webp`, etc. and add corresponding `<img>` tags in `memberships.html` inside `.membership-gallery-inner`.
